# Zipper - Zip your files!

## Description

Have you ever had the problem, where you wanted to transfer files over to a different server, but you can't because there's an upload limit? This is there to fix it.
Zipper loops through your inputted folders and finds every file. It then splits those files into groups that are beneath a customizable range (Starting at 100MiB).
You can also configure the input folder, the output folder and whether to receive debug messages.

## Tech Stack

I have written Zipper in Java, I originally wrote Zipper in Python, the problem however was the speed. It was quite slow compared to what it is now in Java.
